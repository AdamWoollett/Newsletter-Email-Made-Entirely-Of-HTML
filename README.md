# Newsletter Email Made Entirely of HTML

## Overview
The singular HTML file contains not only the structure of the e-mail body, but also in-line CSS styling and all of the images included as base 64 strings. Because all of the content and styling is included in a single file, this file could be easily sent as the body of an e-mail newsletter to make it easy for a distributor to send a stylised e-mail.<br />
A preview of what this project looks like when deployed can be viewed on Vercel at this link: https://villager-newsletter-email.vercel.app/
